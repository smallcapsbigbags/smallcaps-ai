# AIM Radar foundation

Radar is an investigation layer above Analyst 3.3 and Company Memory.

Core rule: an RNS may trigger a Radar setup, but an RNS is never itself the idea.

Pass A establishes deterministic evidence-backed setup detection and persistence. Price-vs-fundamental mismatch signals (`QUIET_IMPROVEMENT`, `UNDERREACTION`, `OVERREACTION`) are intentionally deferred to Pass B so they can be calibrated against market-reaction data rather than guessed.
